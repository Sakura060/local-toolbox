# ToolHub 工具箱门户 v0.11

十个本地工具一个入口：**状态仪表盘 + 启动/停止 + 待办徽标 + Ctrl+K 命令面板 + 跨工具联邦搜索 + 最近动态 + 内嵌预览 + 深色模式 + 光标跟随**。

> **新用户请直接用桌面版**：双击 `启动桌面版.bat`（原生窗口，8650，含"万物皆插件"——
> 把电脑上任意 exe/快捷方式/文件夹/网址/**脚本(.py/.bat/.ps1)** 登记进工具箱，
> 支持命令行参数模板、批量扫描目录导入、开始菜单挑选，详见 `docs/万物皆插件-设计稿.md`。
> 桌面版 v0.2（2026-10-25）；本 README 描述的浏览器门户（8642）并存保留。

## 启动

- 双击 `启动工具箱.bat`（或 `python cli.py serve`）→ http://127.0.0.1:8642
- **托盘常驻**：双击 `启动托盘.bat`（pythonw 无窗口 + 托盘图标，菜单=打开面板/启动各工具/退出）。开机自启已装（当前用户 Startup 文件夹 `toolhub_tray.vbs`；移除：`python cli.py uninstall-autostart`）。

## 能做什么

1. **状态仪表盘**：10 个工具（带专属图标）谁在线、延迟多少，每 5 秒自动刷新（并行探测）。
   - 在线 → 「打开 ↗」新标签直达；「预览」弹窗内嵌 iframe 直接用；「停止」红钮一键结束（**按端口 netstat 反查 PID 强杀进程树**，确认弹窗防误触——无论工具是门户拉起还是自己双击 bat 启动的都能停）；
   - 离线 → 「启动」一键拉起对应 .bat（按钮防抖，自动轮询等就绪）；
   - **待办徽标**：在线工具有待办时挂琥珀色提醒（如捞图"待索引 N 张"，30s 缓存）。
2. **Ctrl+K 命令面板**：打开/启动/停止/预览任意工具 + 全局动作（切主题/清历史/刷新）；`>` 前缀只搜命令；↑↓ 选择回车执行；面板内直接出联邦搜索结果。
3. **联邦搜索（输入即搜）**：打字 300ms 自动搜，并行扇出四源——捞图截图文字（点击看大图）、NoteNest 笔记（Markdown 渲染预览）、文件户口本身世、**ClipVault 剪贴板记录（v0.10 起点击新标签直达条目：自动过滤 + 滚动定位 + 高亮闪烁）**；命中高亮、骨架屏、过期响应作废、搜索历史。
4. **最近动态**：不输关键词也看得到各工具最新条目（相对时间），60s 刷新。
5. **同源代理**：上游工具均无 CORS，门户后端 `/proxy/<工具>/<路径>` 只读透传（段边界白名单 + 拒 `..` + 8MB 上限）。
6. **深色模式**：自动跟随系统 / ☀️ / 🌙 三态，localStorage 记忆。
7. **光标跟随 + 点击涟漪**：小圆点即时跟随 + 细圆环缓动拖尾（悬停可点元素放大），点击处涟漪扩散；`prefers-reduced-motion`/触屏自动禁用。
8. **快捷键**：`Ctrl+K` 面板 · `/` 聚焦搜索 · `Esc` 关面板/弹窗/清搜索。

## 架构

```
toolhub/
  registry.py   注册表（白名单、bat、代理前缀、搜索标志、图标）
  procs.py      进程查找/结束（netstat 端口反查 PID + taskkill /T /F 树杀）
  proxy.py      localcore.net 兼容薄壳（共享件见工作区 localcore/）
  federated.py  联邦扇出 + 归一化 + 待办徽标（30s 缓存，失败折叠永不抛）
  server.py     HTTP 服务（tools/launcher/stopper 可注入）
  tray.py       托盘常驻（pystray + 服务线程，缺失则降级无图标后台）
  autostart.py  开机自启 VBS 安装/卸载（mbcs 编码）
  page.html     单页前端（纯离线资产、esc 全量、深浅双主题令牌）
```

安全设计：启动/停止只认注册表白名单 id；代理段边界白名单 + 拒 `..` + 只 GET + 8MB 上限；上游主机字面量 127.0.0.1；页面动态值全部 esc。

## 已知边界（v0.10）

- 「停止」按端口杀进程：会同时结束你自己手动启动的同端口实例（确认弹窗会提醒）；bat 的 cmd 窗口在进程结束后会停在"按任意键"，需手动关一下。
- 状态探测只判"有 HTTP 应答"，上游 500 也算在线。
- NoteNest 预览已是 Markdown 渲染；iframe 预览依赖上游不设 X-Frame-Options（当前均未设）。
- IAB 内嵌浏览器合成回车不触发搜索（D15，真浏览器正常；已挂 search + keydown 双通道）。
- e2e_server.py 已支持透传 cli 参数（如 --port 8897），验证时避开常驻的 8642。
