# 如何新增一个工具（给工具作者/二次开发者的接入协议）

ToolHub Desktop 的注册表是**插件式**的：一个文件夹 + 一份 `tool.json` 就能被识别，
不需要改任何核心代码。内置的 10 个工具是"自带声明的存量"，你新增的工具走 `apps\` 目录。

## 最小可用示例（工作区里现成活着一个：apps\番茄钟）

```
仓库根目录(repo root)
└── apps\
    └── 番茄钟\
        ├── tool.json     ← 声明文件（必需）
        ├── cli.py        ← 你的程序入口（必需）
        └── page.html     ← 你的界面
```

重启桌面版（或刷新页面），「专注效率」分类下就会出现番茄钟卡片，可以启动/停止/内嵌打开/看日志——
和内置工具完全同权。

## tool.json 字段说明

```json
{
  "id": "pomodoro",                // 必填。ASCII 小写字母/数字/连字符，2-40 位，全局唯一
  "name": "番茄钟",                 // 卡片与详情页显示名
  "icon": "🍅",                    // emoji 图标（也可以用任意 emoji）
  "category": "专注效率",           // 分类名；新分类名会自动出现在左侧导航
  "desc": "25 分钟专注计时器",      // 卡片上的一句话说明
  "version": "0.1",
  "port": 8661,                    // 本机端口 1024-65535，别和现有工具撞（见下方端口表）
  "launch": {
    "argv": ["{python}", "cli.py", "serve"],
    "params": [                    // 启动参数（可选）：argv 里的 {param:名字} 从这里取默认值
      { "name": "dir", "default": "D:\\某目录" }
    ]
  },
  "search": false,                 // true = 参与顶部跨工具搜索（需要实现搜索 API，见下）
  "proxy_prefixes": ["/api"],      // 允许被门户只读代理的路径前缀（缩略图/静态资源等）
  "status": "ready",               // ready=可用 / needs-setup=需配置 / experimental=实验性
  "about": {
    "input": "用户要给什么",        // 详情页"你要给什么"
    "output": "用户能得到什么",     // 详情页"你能得到什么"
    "params": [                    // 展示参数（可选，纯说明文字，不参与启动）
      { "name": "时长", "desc": "默认 25 分钟，界面可调" }
    ]
  },
  "setup_hint": "",                // needs-setup 时详情页显示的一次性配置指引
  "note": ""                       // 卡片上的琥珀色徽标文字（如"实验性：××开发中"）
}
```

## 硬性规则（校验不过 = 这个工具被跳过，并在设置页显示警告）

1. `argv` 必须含 `{python}` 占位符——运行时替换为打包自带的 Python（别人的电脑没有系统 Python）。
2. 程序必须**只监听 127.0.0.1**，端口用 tool.json 里声明的那个。
3. 启动后要在 ~15 秒内可 HTTP 访问 `http://127.0.0.1:<端口>/`（桌面版靠这个点亮状态点）。
4. 界面建议单文件 HTML（和现有工具一致），不要依赖外网 CDN——**全部工具离线可用是产品底线**。
5. 数据写到你自己目录的 `data\` 下；不要写注册表、不要往程序目录外乱放文件。
6. 被停止 = 进程被结束。长任务要自己处理中断（现有工具都这么做）。

## 可选进阶

### 参与跨工具联邦搜索（search: true）

桌面版会并行请求你的 `GET /api/search?q=<词>&limit=<N>`，期望返回：

```json
{ "items": [ { "title": "标题", "snippet": "含关键词的摘要", "when": 1735689600 } ] }
```

`when` 是 Unix 时间戳（秒），用于显示"多久之前"。失败/超时会自动折叠成"离线"，不拖累其他源。

### 提供待办徽标

`GET /api/stats` 返回 JSON；然后在 `desktop/` 的徽标注册表加一个纯函数
（参考 `toolhub/federated.py` 的 `_NOTE_EXTRACTORS`——新工具出徽标 = 注册表加一个函数）。
这一步要改代码，属可选进阶，不影响接入。

### 覆盖内置工具的展示信息

在任何内置工具目录放一份 `tool.json`（id 填它自己的），即可覆盖名称/说明/分类/状态等，
不用动 `desktop/cfg.py`。删掉这份文件即恢复内置声明。

## 开发自查清单

- [ ] `python cli.py serve`（或你的 argv）手动跑一次，浏览器能打开界面
- [ ] tool.json 过校验：id 合法、端口不撞、argv 含 {python}
- [ ] 从桌面版卡片能 启动 → 状态点变绿 → 打开 → 停止
- [ ] 详情页日志里能看到你程序的输出（print 会进日志，记得 flush）
- [ ] 断网可用；数据只在你的目录里
- [ ] 有一段人话的 about.input / about.output（用户不是开发者）
