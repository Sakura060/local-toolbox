# ToolHub 桌面版 · 使用说明（小白版）

> 看不懂任何术语也能照着用。全部操作 = 双击 + 点鼠标，不需要命令行。

## 一、这是什么

把电脑里已有的 10 个本地工具装进**一个窗口**：找工具、启动工具、用工具，都在这一处。
所有数据保存在你自己的电脑上，**不联网也能用**（只有一个例外见第五节）。

## 二、怎么打开

| 场景 | 操作 |
|---|---|
| 日常使用 | 双击 `ToolHub-工具箱门户\启动桌面版.bat` → 弹出工具箱窗口（可能带一个黑色日志窗，最小化别关） |
| 不想看到黑窗 | 双击 `启动托盘.bat` 是旧版；桌面版直接用窗口即可，黑窗只在 .bat 启动方式下出现 |
| 想开机自动打开 | 一次性执行 `python cli.py install-desktop-autostart`（见第 6 节） |
| 用完怎么关 | 直接关窗口即可（工具会继续在后台跑；要彻底停某个工具，在工具卡片上点「停止」） |

> 安装包用户：装好后开始菜单/桌面有「ToolHub 工具箱」图标，双击即用，没有黑窗。

## 三、窗口里怎么用（认卡片就行）

- **左边一列**是分类：文件整理 / 记忆搜索 / 内容笔记 / 隐私安全 / 传输共享 / 专注效率。
- **右边一张张卡片**就是一个个工具：名字 + 一句话说明 + 状态点（绿=正在运行）。
- 卡片上的按钮：
  - **启动**：后台把工具跑起来（几秒后状态点变绿，「启动」变成「打开」）
  - **打开**：在窗口里直接使用这个工具
  - **停止**：结束这个工具（会先弹确认框）
  - **详情**：这个工具是干嘛的、要给什么、能得到什么、运行日志
- 卡片**右上角的 ☆** 点一下变 ★ = 收藏，常用的工具会集中到左边「收藏」里。
- **拖动卡片**可以排顺序，自动记住。
- 顶部搜索框：输入文字，除了找工具，还能**跨工具搜内容**（截图里的字、笔记、文件身世、剪贴板历史）。
- **Ctrl+K**（按住 Ctrl 再按 K）：命令面板，键盘党神器——打几个字回车就能启动/停止/打开任何工具。
- **🩺 环境自检**（左边最下面）：第一次用先点它，它会告诉你这台电脑上哪些工具立即可用、哪个需要一次性准备。

## 四、每个工具是干嘛的（一句话版）

| 工具 | 一句话 |
|---|---|
| FileFlow 文件整理器 | 下载文件夹太乱？自动归类，可预览可撤销 |
| 捞图 截图记忆库 | 记不清哪张截图？搜图里的文字，半秒找到 |
| 文件户口本 | 这个文件从哪来的？下载来源、改名记录一查便知 |
| 文档户口本 | 「方案-final-v3-真的最终版」一堆副本？自动理清谁最新 |
| B站收藏消化器 | 收藏的视频变文字重点，还能搜 |
| NoteNest 本地笔记 | 本地 Markdown 笔记，自动保存 |
| ClipVault 剪贴板时间线 | 复制过的东西都有底，随时找回来 |
| 外发卫士 | 发文件前查隐私（定位、批注、元数据），一键净化 |
| LANDrop 共享/接收 | 电脑和手机同一 Wi-Fi 互传文件 |
| 番茄钟 | 25 分钟专注计时（这个也是"第三方工具接入"的示范） |

## 五、哪些工具需要"一次性准备"（环境自检也会提醒你）

1. **捞图**：第一次用要等它把截图索引完（点启动后让它自己跑；几百张截图约几分钟到十几分钟）。
   ⚠ 建议第一次在**白天**跑：索引时 CPU 会忙，电脑风扇会响，属正常现象。
2. **B站消化器**：第一次转写视频时自动下载语音模型（约 150MB，只此一次）。
   安装包版已**预置模型**，装好即离线可用。
3. **文件户口本**：基础功能开箱即用；"全盘谱系链"需要一次管理员操作（详情页有指引，不用也完全不影响）。
4. **LANDrop**：手机和电脑必须在**同一个 Wi-Fi**；Windows 防火墙第一次会弹窗，勾选"专用网络-允许"。

## 六、命令行方式（给愿意折腾的人，跳过也完全没问题）

```bat
cd /d ToolHub-工具箱门户
python cli.py desktop                        :: 打开桌面版
python cli.py desktop --prefer browser       :: 用默认浏览器打开（窗口有问题时的备用）
python cli.py install-desktop-autostart      :: 开机自动打开工具箱
python cli.py uninstall-desktop-autostart    :: 取消开机自动打开
```

旧版网页门户（`启动工具箱.bat`，浏览器打开）与桌面版**并存不冲突**，想用哪个用哪个。

## 七、换电脑 / 备份

- 便携版：把整个 `ToolHub桌面版` 文件夹拷到 U 盘，在别的电脑双击「启动工具箱.bat」即可——**不需要装 Python**。
- 数据备份：工具数据都在各自的 `workspace\...\data\` 里，整个文件夹复制就是完整备份。
- 设置备份：设置页 → 导出 settings.json（收藏/排序/主题），新电脑导入即还原。

## 八、卸载

- 便携版：删文件夹即完成，不留注册表垃圾。
- 安装包版：控制面板 → 应用 → 「ToolHub 工具箱」卸载；如果装过开机自启，删掉文件夹后执行一次
  `python cli.py uninstall-desktop-autostart`（或直接删除「启动」文件夹里的 toolhub_desktop.vbs）。
