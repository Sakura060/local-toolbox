# ToolHub 桌面版 · 故障排查手册

> 原则：先看现象，再照"怎么办"做。每一条都按"发生了什么 + 为什么 + 怎么办"写。
> 都不管用时：设置页有「程序目录」，把 docs 里的信息提供给维护者。

## 1. 双击启动后什么都没发生 / 窗口一闪就没了

**发生了什么**：桌面程序没起来，或者起来又退出。
**常见原因与怎么办（按顺序试）**：
1. **端口被占**：8650 被别的程序占了。开命令行执行：
   `netstat -ano -p TCP | findstr :8650`，把最后一列的数字（PID）记下来，执行
   `taskkill /PID 那个数字 /F`，再双击启动。
2. **看日志**：用「启动工具箱.bat」（带黑窗版）启动，黑窗里会显示错误原因的第一行。
3. **Python 不在**：源码版运行需要系统装了 Python 3.10+（`python --version` 验证）。
   安装包/便携版自带 Python，不该出现这个——出现说明运行时目录不完整，重新解压/重装。

## 2. 窗口开了，但里面是空白 / 报"桌面服务连不上"

**发生了什么**：界面进程在，后面的本地服务（8650）死了。
**怎么办**：
1. 关掉窗口，用任务管理器结束所有 `python.exe`/`pythonw.exe`（确认没有别的 Python 程序在跑），重新打开。
2. 还不行：命令行进 `ToolHub-工具箱门户` 执行 `python cli.py desktop --server-only`，
   然后浏览器开 `http://127.0.0.1:8650/`——能开说明服务正常，是窗口壳的问题，执行
   `python cli.py desktop --prefer browser` 用浏览器当窗口。

## 3. 点「启动」后状态点一直是灰的

**发生了什么**：工具进程拉起了但没在预期端口上线。
**怎么办**：
1. 打开该工具的**详情页 → 运行日志**，看最后几行——90% 的情况日志里就是答案。
2. 常见原因：
   - 端口被旧实例占着（上一个没关干净）→ 卡片点「停止」，或照第 1 条清端口；
   - 工具目录不完整（缺 cli.py）→ 环境自检会显示 ✗，重装/恢复目录；
   - 模型/依赖缺失 → 环境自检该工具下会有 ✗/⚠ 和具体说明。

## 4. 点「停止」提示"该工具没有在运行"

**发生了什么**：工具不是桌面版拉起的（比如你自己双击过 bat），或者已经退了。
**说明**：「停止」按端口找进程，谁占这个端口都能停。提示这个说明端口上确实没进程——
如果状态点还是绿的，等几秒刷新即可。

## 5. LANDrop 手机搜不到 / 传不了

- 确认手机和电脑连的是**同一个 Wi-Fi**（路由器的"访客网络"会隔离设备）。
- Windows 防火墙第一次会弹窗 → 勾「专用网络」→ 允许。
- 手机浏览器访问日志里显示的地址（不是二维码里的也别慌，日志里也有文字链接）。

## 6. 捞图搜不到截图 / 提示"待索引"

- 第一次使用需要索引：启动后让它跑（黑窗/日志里能看到进度）。
- 想搜系统截图之外目录的图：到捞图界面里加目录。
- 索引很慢/卡住：索引是全 CPU 的，电脑在做别的重活时会慢；让它跑完一次就好。

## 7. B站消化器第一次转写很慢 / 卡在下载

- 首次使用要下载语音模型（约 150MB），取决于网速，几分钟内正常。
- 安装包版已预置模型，不应出现下载——如果出现，说明模型目录没跟着走，把
  `AppToolHub\models\hf` 目录恢复到安装位置即可。
- 转写本身：10 分钟视频在普通电脑上约 1-3 分钟，全程离线。

## 8. 主题/界面显示不对

- 主题：右上角按钮三态切换（跟随系统/浅色/深色）。
- 窗口太小错位：把窗口拉大到 ≥960×620；窄于 900px 会自动收起侧边栏（点 ☰ 展开）。
- 界面卡住不刷新：Ctrl+R 刷新（或嵌入工具页里的「刷新」按钮）。

## 9. 提示"数据目录不可写"

**发生了什么**：程序所在位置没有写权限（比如放在 C:\Program Files 里直接跑）。
**怎么办**：把整个文件夹移到 用户目录 / D 盘 等可写位置再启动。

## 10. 杀毒软件报毒 / Windows SmartScreen 拦截

**发生了什么**：自打包程序没有商业签名，杀软容易误报（这是所有独立打包程序的通病，不代表真有问题）。
**怎么办**：
- SmartScreen：点「更多信息」→「仍要运行」（本程序为本地自用，全部代码在本机可审计）。
- 杀软误报：把 `ToolHub桌面版` 文件夹加入白名单；或改用便携版 zip（解压即用，少一层打包器）。

## 11. 旧版托盘和桌面版会不会打架

不会。旧托盘是 8642，桌面版是 8650，并存正常。如果只想用桌面版：
`python cli.py uninstall-autostart`（移除旧托盘开机自启）即可；不放心就两个都留着。

## 12. 都试了还不行

1. 设置页 → 关于 → 把「程序目录」「Python 版本」记下来；
2. 打开出问题工具的详情页 → 运行日志 → 复制最后 20 行；
3. 带着这两样找维护者（或自己对照源码排查）。
