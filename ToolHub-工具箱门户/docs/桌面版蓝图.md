# ToolHub Desktop 桌面版蓝图（v1.0）

> 任务：把 ToolHub 从"浏览器里的门户"升级为"本地桌面软件"，且**别人的电脑拿到安装包也能直接用**（不需要装 Python）。
> 本文是架构基准。旧的网页门户（v0.11，8642）原样保留，桌面版是新增层，不破坏任何原项目。

## 1. 目标架构

```
┌─────────────────────────────────────────────────────┐
│ ToolHub Desktop（pywebview 原生窗口，WebView2 内核）   │
│  desktop/page.html —— 新版 UI：                       │
│  左侧分类导航 · 工具卡片 · 详情页 · 环境自检 · 设置     │
└───────────────┬─────────────────────────────────────┘
                │ http://127.0.0.1:8650（仅本机回环）
┌───────────────▼─────────────────────────────────────┐
│ desktop/server.py（HTTP 服务，stdlib）                │
│  /api/tools    合并注册表（内置 + tool.json + apps/）  │
│  /api/launch   无窗口静默拉起 + 日志捕获               │
│  /api/stop     按端口反查 PID 树杀（复用 toolhub.procs）│
│  /api/envcheck 环境自检（人话版结果）                  │
│  /api/settings 收藏/排序/首启标记（服务端持久化）       │
│  /api/federated /api/recent /proxy/*  ← 复用 v0.11    │
└───────────────┬─────────────────────────────────────┘
                │ subprocess（CREATE_NO_WINDOW，管道→日志文件）
┌───────────────▼─────────────────────────────────────┐
│ 各工具进程（原样运行，零改动）：                        │
│   python cli.py serve ...（10 个工具各自端口）          │
└─────────────────────────────────────────────────────┘
```

关键决策：

1. **壳**：pywebview（Edge WebView2 内核装进原生窗口）。失败自动降级：Edge `--app` 模式 → 默认浏览器。三档都是"看起来是一个软件"，后两档零依赖。
2. **工具零改动**：桌面版只负责"拉起/停止/嵌界面"，工具代码一行不改（外发卫士、文档户口本是并行会话维护的，必须零侵入）。
3. **注册表插件化**：内置 10 条（沿用 toolhub.registry 的白名单数据，补充分类/输入/输出/参数元数据）+ 每项目可选 `tool.json` 覆盖 + 工作区 `apps\` 目录扫描。**新增工具 = 放一个文件夹 + 一份 tool.json，重启界面即出现**。
4. **端口**：桌面版固定 8650（8642 留给旧门户托盘，互不干扰）。
5. **日志**：拉起工具时管道捕获 stdout/stderr 到 `ToolHub-工具箱门户\data\logs\<id>.log`（UTF-8，超 512KB 留尾），详情页实时看。

## 2. tool.json 配置格式（第三方工具接入协议）

放在工具目录根部（内置工具也可用它覆盖元数据），工作区 `apps\<工具名>\tool.json`：

```json
{
  "id": "pomodoro",
  "name": "番茄钟",
  "icon": "🍅",
  "category": "专注效率",
  "desc": "25 分钟专注计时器",
  "version": "0.1",
  "port": 8661,
  "launch": { "argv": ["{python}", "cli.py", "serve"] },
  "search": false,
  "proxy_prefixes": ["/api"],
  "status": "ready",
  "about": {
    "input": "无需输入，点开始即可",
    "output": "计时结束提示音",
    "params": [{ "name": "时长", "desc": "默认 25 分钟，界面可调" }]
  },
  "setup_hint": ""
}
```

约束（cfg.load 强制校验，不合格直接跳过并给出警告，不影响其他工具）：
- `id`：ASCII 小写字母/数字/连字符，2-40 位，全局唯一。
- `port`：1024-65535。
- `argv`：必须包含 `{python}` 占位符（运行时替换为打包自带的 Python）；不支持其他占位符注入。
- `launch.argv` 的工作目录 = tool.json 所在目录（不允许指到目录外）。

## 3. "别人的电脑也能用"——交付形态

可移植包（portable）+ 安装包（installer）共用同一份构建产物：

```
ToolHub桌面版/
  runtime/                 ← 自带 Python 3.13 embeddable + 全部依赖（pip --target 安装）
  workspace/               ← 11 个项目源码 + localcore + apps/（不含任何个人数据）
  models/hf/               ← 预置 faster-whisper base 模型（消化器离线可用）
  启动工具箱.bat            ← 用 runtime\python.exe 启动，绝不依赖系统 Python
  ToolHub桌面版-setup.exe   ← Inno Setup 打包（可选装开机自启、开始菜单/桌面快捷方式）
```

- 构建时**排除所有个人数据**（data/、*.db、thumbs、transcripts、日志）。
- 捞图 OCR 模型随 rapidocr 包自带；消化器模型预置进 models/hf（环境变量 HF_HUB_CACHE 指过去）；捞图 CLIP（实验性半成品）不打进包，界面标"开发中"。
- 验收方式：把构建产物复制到另一个路径、用"清空 PATH"的环境变量模拟陌生电脑，实测启动与工具拉起。

## 5. 风险与对策（阶段 0 风险清单的落地版）

- pywebview/pythonnet 在 Python 3.13 的兼容性 → 已实测导入成功；真窗口渲染失败则降级 Edge app 模式（零依赖路径）。
- 消化器模型离线加载 → HF_HUB_CACHE 预置 + HF_HUB_OFFLINE=1 实测验证后才写进文档。
- 双击安装包被杀毒误报 → 文档写明"更多信息技术"；提供绿色版 zip 备选。
- 旧托盘（8642）与新桌面版并存 → 阶段 4 给出迁移说明（卸载旧自启一条命令），不自动动用户已有自启项。
