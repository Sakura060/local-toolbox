## 一、产品一句话

**ToolHub 是一个跑在 Windows 上的本地工具箱：一个窗口装下你自己的一套离线工具，
还能把电脑上任意软件"登记"进来当插件——数据全部留在本机。**

三个关键词：**一站式入口**（不用记哪个工具在哪个文件夹）、**万物皆插件**（工具箱自己长大）、
**纯本地**（不联网、不上传、零订阅）。

## 三、核心功能盘点（按"用户旅程"走一遍）

**① 打开**：双击桌面版 → 原生窗口约 1-4 秒打开；首启有环境自检引导；断线有红横幅+自动恢复。
**② 找**：左侧分类导航（文件整理/记忆搜索/内容笔记/隐私安全/传输共享/专注效率）｜顶部全局搜索（跨工具搜截图文字/笔记/文件身世/剪贴板）｜Ctrl+K 命令面板（键盘全程可操作）｜收藏置顶、拖动排序。
**③ 用**：卡片一键启动（后台无窗口拉起+日志捕获）→ 点「打开」工具界面**嵌在窗口里**用 → 「停止」带确认；详情页一处看全：用途/输入/输出/参数/依赖状态/实时日志。
**④ 养（让工具箱长大）**：➕ 导入软件 7 步向导（识别→确认"将执行什么"→试运行→用途→归类）；自动提取图标和版本信息；重复导入会识别；软件搬家后"已失效→重新定位"闭环。
**⑤ 修**：环境自检页（人话版"这台电脑能用什么/怎么配"）；故障排查手册 12 条；所有错误提示带"怎么办"。
**⑥ 分享**：整个安装包/便携 zip 发给别人即可用（自带 Python 运行时+语音模型，预置离线）；设置可导出导入。

**信任底线**（产品宪法）：导入=登记不搬运｜清单无代码（未知字段直接拒绝）｜数据全本地无遥测｜移除插件绝不删用户软件。
