## 一、ToolHub 现在能做什么（功能全景）

### 1. 工具箱本体（桌面版，双击 `启动桌面版.bat`，原生窗口）

| 能力 | 说明 |
|---|---|
| 一个窗口管所有工具 | 10 个内置工具 + 你自己登记的软件，分类导航 + 卡片 + 详情页（用途/输入/输出/参数/实时日志） |
| 全局搜索 + Ctrl+K 命令面板 | 跨工具搜截图文字、笔记、文件身世、剪贴板记录；键盘全程可操作 |
| 一键启动/停止 | 后台静默拉起工具（不用记哪个工具在哪个文件夹）；停止走进程树杀 |
| 工具界面内嵌 | 「打开」按钮把工具网页嵌进窗口里用，不用切浏览器 |
| 收藏/拖动排序/深浅主题 | 常用工具置顶；设置可导出导入 |
| 环境自检 | 人话版"这台电脑能用什么/怎么配"；所有报错都带"怎么办" |
| 断线自愈 | 服务断开显示红色横幅，恢复自动消失 |

| 工具 | 一句话 |

| B站收藏消化器 | 视频转文字重点（本地转写零 API 费；只下音频、用完自动删） |

| 番茄钟 | 专注计时（apps/ 示范插件，自定义 1-180 分钟） |

### 3. 万物皆插件（工具箱自己长大）——本日重点交付

**阶段 A（10-03 已交付）**：
- 把电脑上任意 **exe / 快捷方式 / 文件夹 / 网址 / 文档** 登记进工具箱
- 7 步导入向导（识别→确认"将执行什么"→试运行→用途→归类）；图标自动提取；重复导入会识别；软件搬家后"已失效→重新定位"一键复活
- 铁律：导入只是记路标，**绝不复制/移动/修改你的软件**；移除插件也只删工具箱自己的记录

**阶段 B（10-25 下午交付）**：
- **脚本导入**：.py / .bat / .ps1 都能收（解释器自动找：系统 Python → 工具箱自带）
- **命令行参数模板**（ffmpeg 式）：参数里写 `{file}` `{arg:质量}` 等占位符，每次启动弹表单让你选文件/填参数；跑完一键打开输出文件夹；超时自动强杀
- **批量扫描目录**（#/scan）：指向"绿色软件大本营"一次全收，卸载器/安装器自动过滤，导入后统一补一句话说明
- **开始菜单挑选**（#/startmenu）：已安装软件的快捷方式全部列出（本机实测 165 个），点一个自动进向导
- **拖放区**：从浏览器拖链接直接导入网址；拖本地文件会告诉你"收到了 xxx，请点浏览选中它"（浏览器安全限制拿不到完整路径——这是定论，不是 bug）

**阶段 C（10-25 晚交付）——清单分享 + 商店应用**：
- 「📤 导出全部清单」→ 一个 JSON 文件（**不含任何运行记录/日志**）
- 把文件发给朋友 → 对方「📥 导入分享文件」→ 先预检（每条是什么、路径在不在、有没有冲突）→ 勾选确认才导入
- 换电脑迁移同理：目标路径不存在没关系，插件以"已失效"进入，点"重新定位"指到新位置即复活
- **🛍 商店应用**（深夜交付）：Windows 商店装的 UWP 应用（计算器、Copilot 等 42 个）也能导入了——向导里「从商店应用挑选」，启动交给 Windows 完成（实机验证过）

**工作场景组合（v0.3 深夜交付）**：
- 场景 = 一组常用资源的清单（工具 + 文件夹 + 文件 + 网址），例如「Python 开发」= 笔记 + 项目文件夹 + 文档网页
- 点「▶ 启动」→ 先看预览（哪些将启动/已在运行会跳过/哪条失效）→ 确认 → 按顺序全打开，单项失败不拦后面
- 「⏹ 停止本次启动的工具」只关这次场景拉起的，**你自己在场景启动前打开的程序绝不会被碰**
- Ctrl+K 命令面板里直接搜场景名一键启动

### 候选池（按需排期，均有明确理由）

| 项 | 一句话 | 为什么现在不做 |
|---|---|---|
| 消化器收藏夹批量 | 拉整个 B站收藏夹逐个转写 | 依赖 bilibili API 联网行为，需先确认隐私口径 |
| 插件"7 天没用"徽标 | 提醒清理不用的登记 | 机制现成（徽标注册表），半小时活，随时可插队 |
| 纯本地使用统计 | 知道哪些工具最常用 | 与"无遥测"的边界要设计清楚（纯本地、可看可清） |
| 外发卫士 PDF 净化 | 补齐最后一类文件的"清" | 独立小活，不依赖其他项 |
| 自动更新 | 升级不用重发安装包 | 需要先想清楚更新渠道（GitHub？局域网？），供应链安全要想透 |
| 安装包签名 | 消 SmartScreen 警告 | 需要代码签名证书（约几百元/年），看分发规模再决定 |
| 全局快捷键快速启动 | 任何界面按热键呼出搜索 | 热键冲突可配置+不破坏现有桌面行为，验证成本高 |
| AI 辅助（自然语言找工具等） | "打开 Python 项目环境" | 基础能力稳定前不引入；若做必须可选+默认关+明说数据去向 |
| 旧门户 8642 退役 | 减少双入口认知负担 | 建议桌面版再稳定一个月后执行 |

### 明确不做的（及原因）

- **云同步/账号体系/在线插件商店**——与"纯本地、零遥测"的产品宪法冲突；朋友间传 JSON 分享文件已经覆盖真实需求。
- **把 ToolHub 做成 Flow Launcher 式启动器**——我们有 10 个深度工具 + 插件生态，定位是"工具工作台"不是"另一个启动器"。
