# 文档户口本 — 文档谱系与版本对比

散落各处的同一文档的 N 个副本（`方案-v3-最终版-真的最终版.docx`），自动聚成谱系树：
**谁从谁改出来、哪份最新、有没有分叉**，任意两版逐段对比。与「文件户口本」是姐妹篇：
户口本管文件从哪来，文档户口本管文档怎么变。

## 快速开始

双击 `启动文档户口本.bat` → http://127.0.0.1:8640

- 首次自动扫描 文档/下载 目录（可在页面右上角加目录）
- 同源副本自动聚类 → 簇卡片标注 **最新版** 和 **⚠分叉**
- 点簇看谱系时间线 → 点选任意两份 → 逐段增删改对比

## 工作原理（核心零 AI，可解释）

1. **提取**：docx/pptx/xlsx 解压取段落级文本块（纯 zipfile+ElementTree，恶意 XML 防护内建）
2. **指纹**：每块 = 精确 hash + shingle + 归一化串三通道；块级包含率是版本的领域度量
3. **聚类**：块包含率 ≥0.6 或全文 Jaccard ≥0.55 → 同源簇（并查集）
4. **谱系**：包含率 ≥0.75 判祖先/后代；对称小改动按 mtime 定向；传递约简去冗余边；
   无后代的节点 = 终版候选，多个终版 = ⚠分叉（诚实标警，不瞎判方向）
5. **重复副本**：归一化块集合精确相同 → 标「重复副本」

## CLI

```
python cli.py scan [<目录>...]      # 扫描并重建谱系（增量幂等，~$ 锁文件自动跳过）
python cli.py clusters              # 控制台列出同源簇
python cli.py diff <idA> <idB>      # 控制台逐段对比
python cli.py serve [--port 8640]   # Web（自动开浏览器，后台每小时增量重扫）
python cli.py stats
```
