# NoteNest — 本地 Markdown 笔记服务

本地优先的个人笔记工具：**笔记是纯 .md 文件**，服务只提供便利（网页编辑器、搜索、预览），数据随时可以用任何编辑器直接打开。纯 Python 标准库，零第三方依赖，仅绑定 127.0.0.1。

## 快速开始

```bat
python cli.py                        :: 笔记目录默认 ~/NoteNest，端口 8890
python cli.py --dir D:\我的笔记 --port 8080
```

打开 http://127.0.0.1:8890/ 即用。

## 功能

- **两栏界面**：左侧搜索 + 笔记列表（摘要/时间），右侧笔记区；**点开默认是查看态**，点「✏ 编辑」才进入编辑
- **Markdown 编辑与实时预览**：自研轻量渲染器（标题/列表/引用/代码块/加粗/斜体/链接/分隔线），渲染前先转义 HTML，杜绝注入
- **文字颜色标注**：选中文字后**点色点一次即上色**（也可 Alt+1~7 上色、Alt+0 去色；红/橙/黄/绿/蓝/紫/灰，另支持任意十六进制）。**编辑时颜色就实时可见**（标记画成淡灰），预览里同样渲染成彩色；再点同色=取消、换色=替换，不会叠加。落盘的是纯文本标记 `{red}重要{/red}`，任何编辑器都能直接读；笔记列表摘要会自动去掉标记。**多段上色**：①一次框选多行 → 逐行上色（列表/标题/引用的结构不会被破坏）；②点「🖌 连续」蘸好一个颜色，之后每次选中文字就自动上色，按 Esc 退出——十几段也能一口气刷完
- **图片与文字同用**：📷 选文件 / **直接 Ctrl+V 粘贴截图** / 把图片拖进来，三种方式都能插图。图片存在笔记目录的 `assets/<笔记id>/`（文件名=内容哈希，同一张不会存两份），正文里写标准相对 Markdown；渲染只认本机 `assets/` 路径，外链图片不会被加载
- **搜索**：标题 + 正文子串匹配，不区分大小写，输入防抖
- **快捷键**：Ctrl+S 保存；Alt+1~7 上色 / Alt+0 去色；刷子模式 Esc 退出；未保存修改有 ● 标记
- **统计**：笔记数 / 总大小 / 存储目录一目了然

## 数据格式

每条笔记是笔记目录下的一个 `<id>.md` 文件：

```markdown
# 笔记标题

正文……
```

- 首行 `# 标题` 即标题；没有标题行则取首个非空行
- 用别的编辑器改动文件后刷新页面即可看到（每次请求都重新读盘）
- 图片存在同一目录的 `assets/<笔记id>/` 下，正文写的是相对路径 `![](assets/<id>/<哈希>.png)`——用 Typora / VSCode 打开这台机器上的 .md，图片照样显示
- 颜色标注写进正文也是普通文本：`{red}重要{/red}`（色名 `red`/`红`…，或 `{#e11d48}`）；在 NoteNest 里编辑和预览都显示为彩色，别的编辑器里就是这段标记

## 安全设计

- 仅监听 127.0.0.1，不暴露局域网
- 笔记 id 白名单校验（`[a-z0-9]{6,16}`）+ 路径双保险，杜绝任意文件读写
- 单篇笔记上限 512KB；超限请求先排空再回 400，保持连接语义正确
- 前端 Markdown 渲染前转义 HTML
- 图片：按文件头认类型，只收 png/jpg/gif/webp/bmp，单张 ≤10MB；渲染只认本机 `assets/` 相对路径，http(s)/svg/`..` 一律不加载（数据不出本机）

## 目录结构

```
notenest/
  store.py     存储层（线程安全 CRUD + 搜索 + 标题解析）
  server.py    HTTP 服务 + REST API
  page.html    单页应用（编辑器 + Markdown 渲染器）
cli.py         命令行入口
tests/         单元 + 集成测试

<笔记目录>/
  <id>.md      每篇笔记（纯 .md）
  assets/<id>/ 该笔记的图片（文件名 = 内容哈希）
```
