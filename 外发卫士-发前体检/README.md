# 外发卫士 — 发文件前 30 秒体检

把"看不见的泄露"变成"看得见的报告"：拖入要发出去的文件，揪出藏在里面的隐私，
一键净化另存（**绝不覆盖原件**）。纯解析零 AI，离线可信。

## 快速开始

双击 `启动外发卫士.bat` → http://127.0.0.1:8641 （或直接拖文件进窗口）

## 能查出什么

| 级别 | 项 |
|---|---|
| ★ 高危 | 批注未删除、修订记录未接受、隐藏工作表、内嵌对象、EXIF GPS 定位、本机路径/用户名泄露、模板字段路径、PDF 内嵌附件/JS |
| ☆ 注意 | 作者/公司元数据、自定义属性（如 AIGC 标记）、缩略图首屏、演讲者备注、外部工作簿引用、拍摄设备 |
| · 提示 | 版本号、拍摄时间、生成器信息 |

## 一键净化（白名单重组）

- OOXML：清空元数据、删除批注/备注/缩略图/自定义属性/外部引用部件、**接受全部修订**
  （w:del 删除、w:ins 展平）、隐藏工作表转可见；同步清理 rels 与 Content_Types 引用
- 图片：重编码剥离全部 EXIF
- 结构自校验：产物必须通过「rels 引用完整 + Content_Types 一致 + XML 良构」检查，
  否则拒绝交付（宁可不净也不给坏文件）
- 净化后自动复检：正文内容类问题（如手写路径、内嵌对象）诚实标「需手工处理」

真实案例（2026-09-27）：一份个人简历 docx 查出作者含本机用户名 + 自定义属性 `AIGC`；
净化后复检归零，Word 可正常打开。

## CLI

```
python cli.py check <文件>              # 控制台体检报告
python cli.py sanitize <文件> [-o 输出]  # 净化另存（拒绝同路径覆盖）
python cli.py serve [--port 8641]       # Web（自动开浏览器）
```

## 测试

```
python -m unittest discover -s tests   # 30 项：合成 OOXML 体检/净化往返/EXIF/PDF/ZIP/HTTP 全链路
```

## 边界（诚实声明）

- PDF v0.1 只检不清（建议重新导出）；zip 只报告内含路径
- 内嵌对象自动删除会破坏正文引用 → 标手工处理
- 深度 PDF（xref 流压缩）元数据可能漏检，v0.2 引入解析器

## 隐私

体检与净化全部本地完成；上传工作区 `data/uploads/` 仅保留 24 小时自动清扫；零联网。
